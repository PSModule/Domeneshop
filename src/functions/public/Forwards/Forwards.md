# Forwards

Public commands for managing HTTP forwards on Domeneshop domains.

## Commands

- `Add-DomeneshopForward`: Adds an HTTP forward to a domain.
- `Get-DomeneshopForward`: Lists HTTP forwards or gets a forward by its hostname.
- `Remove-DomeneshopForward`: Removes an HTTP forward from a domain.
- `Set-DomeneshopForward`: Updates an HTTP forward on a domain.
