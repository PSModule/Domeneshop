# DNS

Public commands for managing DNS records on Domeneshop domains.

## Commands

- `Add-DomeneshopDnsRecord`: Adds a DNS record to a domain.
- `Get-DomeneshopDnsRecord`: Lists DNS records or gets a record by its numeric identifier.
- `Remove-DomeneshopDnsRecord`: Removes a DNS record from a domain.
- `Set-DomeneshopDnsRecord`: Updates a DNS record on a domain.
